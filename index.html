Vilka Story

Платформа для монетизации контента

Задача: Разработать веб-платформу для публикации глав с автоматическими платежами.

Решение: Next.js + Supabase + Юкасса. Система подписок, админ-панель для авторов.

Результат: Продукт запущен, авторы получают выплаты автоматически.

Hobby 101

Офлайн-гид с системой мотивации
